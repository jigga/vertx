= Vertx

image:https://img.shields.io/badge/vert.x-4.5.11-purple.svg[link="https://vertx.io"]

This application was generated using http://start.vertx.io

It contains the reproducer code for the `OutOfMemoryError: direct memory` issue that occurs when serving (`HTTP GET`) large payloads (70 MB) under heavy load.

== Running the server

To launch the server, run:
```
./gradlew :server:run
```

== Running the client

To run the client to put the load on the server, run:
```
./gradlew :client:run
```

After running the client for some time (typically several seconds), you would start seeing the below exceptions in the server log.
